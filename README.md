# Ultimate Game Show Controller V5.1.1

Upload all six files in this folder to the root of the existing public GitHub Pages controller repository: `index.html`, `battle.html`, `battle-controller.js`, `peerjs.min.js`, `ultimate-game-show-logo.png`, and `README.md`. Replace the older files. Do not upload only the HTML files or add an enclosing folder.

This controller includes queued Battle Royale joins, automatic reconnection, join timeouts with a visible retry button, roster reset handling, fresh UUID reconnection, a reliable single-tap wheel button, compact photo payloads, official logo artwork, haptic turn alerts, full-session reset handling, and correctly centered bonus-card text on phones and tablets.

`index.html` remains the Classic Wheel controller. `battle.html` is the separate Solve the Puzzle: Battle Royale controller. Publishing Battle Royale does not replace the Classic controls.

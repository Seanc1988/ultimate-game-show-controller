# Ultimate Game Show Controller V4.12.1

Upload all four files in this folder to the root of the public GitHub Pages controller repository: `index.html`, `peerjs.min.js`, `ultimate-game-show-logo.png`, and `README.md`. Do not upload only the HTML file or add an enclosing folder.

This controller includes fresh UUID reconnection, a reliable single-tap wheel button, compact photo payloads, official logo artwork, haptic turn alerts, full-session reset handling, and correctly centered bonus-card text on phones and tablets.

V4.12.1 does not change phone wheel behavior or contestant controls. It only corrects the alignment and wrapping inside the circular bonus-card display.

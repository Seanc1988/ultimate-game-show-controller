# Ultimate Game Show Controller V5.0.0

Upload all five files in this folder to the root of the public GitHub Pages controller repository: `index.html`, `battle.html`, `peerjs.min.js`, `ultimate-game-show-logo.png`, and `README.md`. Do not upload only the HTML files or add an enclosing folder.

This controller includes fresh UUID reconnection, a reliable single-tap wheel button, compact photo payloads, official logo artwork, haptic turn alerts, full-session reset handling, and correctly centered bonus-card text on phones and tablets.

`index.html` remains the Classic Wheel controller. `battle.html` is the separate Solve the Puzzle: Battle Royale controller. Publishing Battle Royale does not replace the Classic controls.

# Ultimate Game Show Controller V5.3.1

Upload all nine files in this folder to the root of the existing public GitHub Pages controller repository: `index.html`, `battle.html`, `battle-controller.js`, `audience.html`, `battle-audience-remote.js`, `peerjs.min.js`, `qrcode.min.js`, `ultimate-game-show-logo.png`, and `README.md`. Replace the older files. Do not upload only the HTML files or add an enclosing folder.

This controller includes the same STUN/TURN internet relay configuration used by the working Classic controller, the original game's word-aware 4×14 puzzle-board layout, exact live letter synchronization, optional voice answer entry, queued Battle Royale joins, automatic reconnection, reliable round/game/all-time leaderboards, winner vibration/flash alerts, a seven-second final-answer window, autoplay countdown support, and the beta remote audience display.

`index.html` remains the Classic Wheel controller. `battle.html` is the separate Solve the Puzzle: Battle Royale controller. `audience.html` is the internet-connected remote audience display. Publishing Battle Royale does not replace the Classic controls.

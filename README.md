# Ultimate Game Show Controller V4.7

Upload all three files in this folder to the root of the public GitHub Pages controller repository. Keep `index.html` and `peerjs.min.js` beside each other. Do not upload only the HTML file.

This controller includes automatic heartbeat recovery, touch-flick wheel control, haptic turn alerts, server-owned Wild Card visibility, and full-session reset handling.


## V4.8
Use `index.html` and `peerjs.min.js` together with `ultimate-game-show-live-logo.png`. The controller now uses a tap-to-spin control and clears stale sessions when the host starts fresh.
